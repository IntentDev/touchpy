touchpy.Comp🔗

class touchpy.Comp🔗
class Comp(flags: CompFlags = 37, fps: float = 60, device: int = 0, td_path: str = '')🔗
class Comp(
tox_path: str,
flags: CompFlags = 37,
fps: float = 60,
device: int = 0,
td_path: str = '',
)

Representsa TouchDesigner component loaded in a TouchEngine instance.

Parameters:

  • flags (CompFlags) – The flags for the component (default: CompFlags.INTERNAL_TIME_AUTO | CompFlags.CUDA_STREAM_DEFAULT).

  • device (int) – The hardware device index to run the component on (default: 0).

  • td_path (str) – The path to the TouchDesigner installation if no path is set (default: “”) then either: - The most recent TD install will be used. - The path set in TOUCHENGINE_APP_PATH environment variable if it exists. - The path set in shortcut or symlink located in the same directory as the component to be loaded.

  • tox_path (str) – The path to the .tox file.

  • flags – The flags for the component.

  • device – The hardware device to run the component on.

  • fps (int) – The frames per second of the TouchEngine instance.

  • td_path – The path to the TouchDesigner installation.
