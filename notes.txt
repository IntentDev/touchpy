Currently functioning in Python:

Comp class
	- load_tox()
	- loaded()
	- update() - called in a loop repeatedly
	- start() - starts a loop that calls update() repeatedly (run())
	- stop() - stops the run loop that calls update()
	- set_on_frame_callback() - sets a callback function to be called every frame by the update() function when 
		data is ready to be retrieved 
	- in_tops - InTopLinks container of InTopLink instances 
	- out_tops - OutTopLinks container of OutTopLink instances 
	- in_chops - InChopLinks container of InChopLink instances
	- out_chops - OutChopLinks container of OutChopLink instances
	- in_dats - InDatLinks container of InDatLink instances
	- out_dats - OutDatLinks container of OutDatLink instances
	- par - ParLinkCollection of ParLink instances

Links class (OutTopLinks, InTopLinks, OutChopLinks, InChopLinks, OutDatLinks, InDatLinks classes)
	- num_links() - returns the number of OutTopLink instances in the container
	- link_names() - returns a list of the names of the OutTopLink instances in the container
	- [index] - returns the [Derived]Link instance at the given index
	- [name] - returns the [Derived]Link instance with the given name

ParLinkCollection class
	- count - number of ParLinks in the collecion (Pars on the Comp)
	- names - list of names of all available ParLinks
	- [name] - get a ParLink by name

OutTopLink class
	- cuda_memory() - returns a CudaMemory instance
	- as_dlpack() - returns a Dlpack capsule
	- as_tensor() - returns a PyTorch tensor

InTopLink class
	- copy_cuda_memory(cudamemory) - copies the data from a CudaMemory instance
	- from_dlpack(capsule) - sets the data from a Dlpack capsule (overloads for 1, 2, 3, 4 component arrays)
	- from_tensor(tensor) - sets the data from a PyTorch tensor (overloads for 1, 2, 3, 4 component arrays)
	
OutChopLink class
	- chan_names() - returns a list of the channel names
	- as_numpy() - returns a numpy array (will automatically copy the data if needed)
	- as_numpy_ref() - returns a numpy array reference (will not copy the data, unless explicitly copied)

InChopLink class
	- from_numpy(array, names=[]) - sets the data from a numpy array, with optional channel names

OutDatLink class
	- as_string() - returns the data as a string
	- as_table() - returns the data as a DatTable instance
	- getTypeDescription() - returns the type description of the data (string or DatTable)

InDatLink class
	- from_string(string) - sets the data from a string
	- from_table(table) - sets the data from a DatTable instance
	- from_list(list) - sets the data from a list of lists

ParLink class
	- val - property to get or set the value of the parameter
	- set(val) - sets the value of the parameter
		- various overloads for multi-component parameters:
			- set([val1, val2, val3, val4])
			- set(val1, val2, val3, val4)
			- set(Color(val1, val2, val3, val4))
			- set(Float2(val1, val2))
			- etc...
	- get() - gets the value of the parameter


ParLinkValue types: Int, Float, String, Color, Float2, Float3, Float4, Int2, Int3, Int4, Bool

CUDADataType enum class
	- Float32, Int32, UInt8

CudaMemoryShape class
	- width
	- height
	- num_components
	- component_size
	- data_type (CUDADataType)
	- strides (array of 3 ints)

CudaMemory class
	- ptr - property to get or set the pointer to the data
	- size - property to get or set the size of the data
	- shape - property to get or set the shape of the data

ComponentMask enum class
	- R, G, B, A, RGB, RGBA
	- used to mask components of a tensor (e.g. comp.out_tops[0].as_tensor(ComponentMask.R | ComponentMask.B))
